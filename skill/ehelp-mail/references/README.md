# 易邮｜邮件往来联系人整理

**版本：0.2.6（WorkBuddy 市场体验候选）**

一句话：把本机已同步的邮件往来整理成可持续更新的联系人台账，生成易读网页和 Excel。默认一个邮箱、最近30天、每批最多200条来源记录、单页最多展示100人。**它不是邮箱全量导出，也不会替你判断客户是否流失。**

## 我怎么用

在 WorkBuddy 安装 Skill 后，你可以直接说：

- 「帮我整理最近30天邮件里往来过的联系人，导出 Excel。」
- 「更新我的联系人台账，看看本批新增和变化了多少人。」
- 「把我指定的这个邮箱标记为关注，备注下周联系。」

Agent 应先检查能否在你的 **Windows 本地电脑**运行，确认邮箱来源和账号，再告知读取范围并进行有界预览。你已经明确要求整理时，可在预览后执行本地更新，生成 HTML 和 Excel；只查看能力、不要求整理时，不写入台账。

## 安装与环境要求

- Windows + 已登录并完成本地同步的[网易邮箱大师](https://dashi.163.com/) 是主要试用路径；[Foxmail](https://www.foxmail.com/win/zh/) 是测试适配，正在同步引起数据变动的场景尚未现场验收。
- Python 3.11 或更新版本；首次需要联网安装已固定版本的 Python 依赖（到 Skill 目录内的隔离虚拟环境）。不会安装数据库服务。
- **平台运行环境限制**：WorkBuddy 的付费资产可能在云端运行，是否能访问消费者 Windows 电脑的本地邮件文件尚无实测结论。如果无法直接访问本机，不应把 ZIP 导入成功视为功能可用，也不应让你上传整份邮箱数据库；请走 WorkBuddy 平台反馈渠道。

## 文件在哪里

联系人台账默认在 `%LOCALAPPDATA%\ehelp-mail\contacts.sqlite3`，用于保存联系人和用户标记（并包括邮件主题、日期、收发关系和去重证据）；每次 HTML/Excel/计划文件保存在用户指定的独立结果目录。**文件没有额外加密**。默认不会复制整个邮箱数据库、读取正文或附件、发送邮件，也不会把联系人上传给开发者。第一次下载依赖可能联网；WorkBuddy 对话本身遵循平台服务的数据处理规则。

## 免费/付费边界与数据所有权

本包没有单独的许可证要求。WorkBuddy 市场上是否付费、按月或一次性、具体价格，均以市场展示页为准；不存在付费后必须再到站外购买才能使用核心联系人整理功能的附加条件。联系人是用户自己的业务数据，平台评价和使用反馈应避免包含客户信息。

## 可持续使用

- 每次整理最多读取指定批次，`scan_complete=false` 意味着**还没读完所选本地范围**；用户可主动要求“继续下一批”。后续重复使用可以检查新的往来联系人和最近批次的变化。
- 人工关注、姓名确认、备注会在本地台账中保留；Excel 和 HTML 是快照，修改导出表格不会自动写回。
- 换客户端或来源路径时不能直接合并；升级前应先备份联系人台账。WorkBuddy 市场 ZIP 不能直接传给程序自带的 `upgrade` 命令；请通过市场平台的更新流程处理。
