# 易邮·第一次怎么用（用户语言与 Agent 操作分离）

## 最简单的 3 句话

1. **第一次**：「帮我整理最近 30 天邮件里往来过的联系人，生成 Excel。」
2. **过几天**：「更新联系人台账，告诉我本次有哪些新增和变化。」
3. **持续使用**：「把 customer@example.com 标为关注，备注下周联系，再导出我关注的人。」

## 第一次得到什么

本地 HTML 查看页中的“累计联系人 / 我关注的人 / 本批新增 / 本批更新 / 累计邮件证据”，以及本机 Excel。HTML 和 Excel 是快照，继续更新必须回到对话要求生成新报告。

## 重要限制

- 这不是把邮箱全部导出。默认只看一个邮箱，最近 30 天、每批最多读取 200 条来源记录。邮箱尚未同步到本机的邮件不在结果里。
- HTML 和 Excel 每次显示前 100 人；更多人保留在本地台账，不因展示限制丢失。
- Foxmail 属于试用适配；正在同步发生变化时可能中断并提示重试。Mac 和 Linux 的实际邮箱扫描尚未验收。
- 只读取邮件头部（收发件地址、时间、主题），不读正文/附件，不发信，整理时不连接邮箱服务器。邮件主题也可能是私人信息；输出文件和台账未额外加密，请保存在自己有权限控制的电脑目录。
- 首次需要在 Windows 电脑上具备 Python 3.11+ 和已同步的邮件客户端。依赖安装可能联网，整理执行不主动向外上传联系人。
- 如果 WorkBuddy 当前 Skill 运行于云端、无法访问本机文件，则不能直接完成本机扫描。请使用平台反馈渠道说明这一情况；不要上传整份邮箱或联系人的原始文件来绕过限制。

## 安全操作口径

预览只告诉你将读取的数量和范围；真正写入本地台账需要执行预览结果。不会自动替你决定重要客户，也不会自动把联系人添加进外部客户管理系统。
