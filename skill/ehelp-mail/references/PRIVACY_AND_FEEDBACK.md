# 易邮·隐私、适用范围与反馈

**本版本提供的功能**：整理本机已同步邮件头部、建立本地联系人台账、持续更新、人工关注/备注、HTML/Excel 导出、备份及受控升级。不是邮件客户端、CRM 或邮件代发服务；不包含 JCTrans、企业自动化实施、飞书同步或其他需要另付费的核心功能。

**读取什么**：选择账号的邮件头（收/发件人、时间、主题、邮件来源与去重信息）。**保存什么**：必要的去重证据、本地联系人关系、用户备注和扫描进度。**不读取什么**：正文、附件、邮箱登录凭据。**不执行什么**：发信、自动报价、外部数据上传。首次依赖安装可能连接 Python 软件包源；使用 WorkBuddy 对话服务自身可能涉及平台侧文本处理，建议不要把联系人明细粘贴进对话。

**本地位置**：Windows 默认 `%LOCALAPPDATA%\ehelp-mail\contacts.sqlite3`；预览和导出目录由用户或 Agent 为本次任务指定。文件并未做独立加密，请使用适当的电脑账户和磁盘权限。删除本地台账会失去已整理的联系人和备注；删除前应手工备份。不提供云备份或跨设备同步承诺。

**运行条件**：Windows、Python 3.11+、已登录并同步到本机的网易邮箱大师；Foxmail 是测试来源。Skill ZIP 被平台解析成功并不代表平台付费运行环境具有本机文件访问能力。无本机执行权限时应停止，不能虚报成功。

**如何反馈**：请先使用 WorkBuddy 市场页或对话中的平台反馈渠道。建议说明 Skill 版本号（`version`）、操作步骤、操作系统、客户端类型、返回的简要状态代码、是否能打开结果文件。不要上传邮箱密码、完整错误日志、数据库文件、客户姓名邮箱、邮件主题、Excel 或整份邮件。若需要技术人员排查，应先获得明确授权并脱敏。

**收费**：最终价格和计费方式以 WorkBuddy 市场页发布信息为准。本 ZIP 内不实施独立许可证，不设置付费后必须站外购买的隐藏条件，也不以填写联系方式作为核心功能的前置条件。
